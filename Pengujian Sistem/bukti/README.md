# Folder Bukti Pengujian

Simpan tangkapan layar bukti eksekusi tiap kasus uji di folder ini.

**Aturan penamaan:** huruf kecil, sama dengan kolom *Bukti* pada
`../03-hasil-pengujian.md` — yaitu `<kode-kasus>.png`.

Contoh: `pp-01.png`, `df-05.png`, `cr-01.png`, `ap-03.png`, `up-01.png`.

Tips:
- Satu kasus satu gambar berisi bukti inti (pesan kesalahan, kondisi
  sebelum–sesudah, atau respons Swagger dengan kode statusnya).
- Gunakan Snipping Tool (Win+Shift+S).
- Untuk skripsi, pilih 2–4 gambar paling representatif sebagai
  "Gambar 4.x" di naskah; selebihnya cukup di lampiran.
